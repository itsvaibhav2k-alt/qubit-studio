- Font source file: `InstrumentSans[wdth,wght].ttf` (unmodified, renamed locally to `InstrumentSans-Variable.ttf`).

Loaded from `/fonts/instrument-sans/InstrumentSans-Variable.ttf` by `workspace.css` with `font-display: swap`. No runtime third-party font requests or font package dependency.
